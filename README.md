# Customer Churn Prediction

## Project Description
This project predicts whether a customer will leave a company or continue using its service.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Files
- customer_churn.py - Python code
- customer_churn.csv - Customer data
